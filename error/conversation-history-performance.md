# 外部任务运行中会话无响应

**症状**　旧会话续跑时界面卡顿，外部窗口请求超时；大历史打开时出现长时间停顿。

**根因**　`tracked-run.ts` 曾深度监听整个消息数组，强制展开消息的惰性代理，并在流式更新时重复统计工具记录。活动会话的完整详情也曾在 Renderer 无界拼接和解析。

**处理**

- 外部任务只观察运行生命周期的明确字段，查询状态时再读取最新回复和工具统计。
- 完整历史加载检查聚合与实际流数据预算；大详情在 Worker 拼接和解析，成功、失败、取消后均释放。
- 超限或加载失败保留原记录，不返回可被保存为完整会话的部分数组。
- 活动记录读取失败不得丢弃已读的分页摘要；恢复到独立新会话并提示用户从历史列表选择。不得把原活动 ID 与空消息绑定，否则后续保存可能覆盖旧记录。
- 不直接截取最近 N 条替代完整记录：持久化 ID/位置基线与模型续聊仍依赖完整消息。

**预防**　回归使用真实消息惰性代理，断言流式更新不读取旧 payload；覆盖大详情、取消、Worker 失败、UTF-8 字节和历史续聊。验证记录见 [报告](../test/2026-11-22-conversation-freeze.md)。
